# 🕵️ The Deductive Game – Version 5.0

### A Cartoon-Style Detective Mystery Game Built with Python

**The Deductive Game** is an interactive detective mystery game developed using Python and Pygame. Put your detective skills to the test, crack the secret three-digit code, analyze clues, and identify the criminal among three suspects!

Version 5.0 brings enhanced cartoon-style animations while preserving the original gameplay, special hints, suspects, sound effects, and detective mystery experience.

---

## 🎮 Game Features

- **Cartoon-Style Animations:** Enhanced animated characters and visual effects.
- **Animated City Background:** A mysterious rainy city with buildings, glowing streetlights, and road reflections.
- **Moving Vehicles:** Animated cars with rotating wheels.
- **Detective Character:** A cartoon-style detective character.
- **Three Suspects:** Investigate three different suspects and identify the criminal.
- **Secret Code Challenge:** Crack a randomly generated three-digit secret code.
- **Special Hint System:** Unlock helpful clues as you make incorrect guesses.
- **Sound Effects:** Interactive audio feedback for clicks, incorrect guesses, hints, and victories.
- **Limited Attempts:** Solve the mystery within 10 attempts.
- **Victory and Failure Screens:** Discover whether you successfully solved the case.

## 💡 Special Hint System

The game provides three special hints to help players solve the mystery.

| Incorrect Attempts | Hint |
|---|---|
| 3 attempts | Reveals one digit in the secret code |
| 6 attempts | Reveals whether the middle digit is even or odd |
| 9 attempts | Reveals the exact last digit |

Hints remain available once unlocked, helping players combine clues and solve the mystery.

## 🕹️ How to Play

1. Launch the game.
2. Click **START NEW CASE**.
3. A random three-digit secret code is generated.
4. Enter three different digits from 1 to 9.
5. Submit your guess.
6. Analyze the feedback about correct digits and positions.
7. Unlock special hints after every three incorrect guesses.
8. Identify the criminal by cracking the secret code.
9. Solve the case within 10 attempts!

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.x
- Pygame

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/the-deductive-game.git
```

### Step 2: Navigate to the Project Folder

```bash
cd the-deductive-game
```

### Step 3: Install Pygame

```bash
pip install pygame
```

### Step 4: Run the Game

```bash
python main.py
```

*If your Python file has a different name, replace `main.py` with your actual filename.*
